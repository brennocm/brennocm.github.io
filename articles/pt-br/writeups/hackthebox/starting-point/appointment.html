Appointment

HackTheBox, Very Easy

Appointment introduz o SQL Injection: a manipulação de consultas SQL para alterar o comportamento da aplicação, aqui, para burlar uma tela de login.

Reconhecimento

O Nmap identifica um servidor web (porta 80). O gobuster confirma a página principal index.php, que exibe um formulário de login.

nmap -sC -sV --min-rate=1000 <IP>
gobuster dir -w /usr/share/wordlists/dirb/common.txt -u http://<IP>

Exploração

No campo de usuário insere-se o payload admin' #. O comentário # anula o restante da query (incluindo a checagem de senha); como o usuário admin existe, a autenticação é concluída e a flag aparece.

usuário: admin' #
senha:   (qualquer)
