Meow

HackTheBox · Very Easy by Brenno M.

Meow é o primeiro laboratório do path Starting Point e introduz os conceitos básicos de reconhecimento e enumeração de serviços. O foco é o protocolo Telnet, um serviço de acesso remoto sem criptografia que, quando mal configurado, permite autenticação com usuários padrão.

Reconhecimento

A validação de conectividade com o host é feita com ping, seguida de uma varredura de serviços com o Nmap. A varredura revela apenas a porta 23 (Telnet) aberta.

ping -c4 <IP>
nmap -sV -sS <IP>

Exploração

Com o Telnet exposto, testam-se usuários padrão. O login com o usuário root é aceito sem senha, resultado de uma configuração indevida do serviço.

telnet <IP>
# login: root  (sem senha)
id
ls -la
cat flag.txt

O acesso administrativo é obtido diretamente, e a flag é localizada no diretório do usuário.
