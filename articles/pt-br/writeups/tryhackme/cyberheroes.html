CyberHeroes

TryHackMe · Easy by Brenno M.

CyberHeroes é um desafio web que ilustra o perigo de validar autenticação no lado do cliente. Toda a lógica de login está no JavaScript da página, e basta lê-la para derivar a senha.

Reconhecimento

O Nmap revela SSH e HTTP. A página inicial contém um formulário de login que não faz requisição ao servidor, indício de validação client-side.

nmap -p- --min-rate 1000 -sV <IP>

Análise do JavaScript

No código-fonte, a função de checagem compara o usuário com um valor fixo e a senha com o retorno de uma função ReverseString() aplicada a uma string embutida. Ou seja, a senha é simplesmente a string embutida invertida.

function checkPass(uname, pass) {
  if (uname === 'h3ck3rBoi' && pass === ReverseString('...string embutida...'))
     { /* concede acesso */ }
}

Bypass

Invertendo a string embutida no console do navegador obtém-se a senha; com o usuário h3ck3rBoi e essa senha, o login é concluído e a flag é revelada. Lição: nunca confie em validação client-side.

// no console do navegador:
ReverseString('...string embutida...')
// login: h3ck3rBoi : <SENHA_DERIVADA>
