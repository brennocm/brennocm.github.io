CyberHeroes

TryHackMe · Easy by Brenno M.

CyberHeroes is a web challenge illustrating the danger of validating authentication on the client side. All login logic lives in the page's JavaScript, and reading it is enough to derive the password.

Reconnaissance

Nmap reveals SSH and HTTP. The landing page has a login form that makes no server request, a hint of client-side validation.

nmap -p- --min-rate 1000 -sV <IP>

JavaScript analysis

In the source, the check function compares the user with a fixed value and the password with the output of a ReverseString() function applied to an embedded string. In short, the password is simply the embedded string reversed.

function checkPass(uname, pass) {
  if (uname === 'h3ck3rBoi' && pass === ReverseString('...embedded string...'))
     { /* grant access */ }
}

Bypass

Reversing the embedded string in the browser console yields the password; with user h3ck3rBoi and that password, the login succeeds and the flag is revealed. Lesson: never trust client-side validation.

// in the browser console:
ReverseString('...embedded string...')
// login: h3ck3rBoi : <DERIVED_PASSWORD>
