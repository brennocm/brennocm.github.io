Preignition

HackTheBox, Very Easy

Preignition introduces directory busting: brute-forcing directories and files on a web server, here using gobuster.

Reconnaissance

Nmap identifies an active web server. Gobuster then enumerates directories and reveals admin.php.

nmap -sV <IP>
gobuster dir -w /usr/share/wordlists/dirb/common.txt -u http://<IP>

Exploitation

The admin.php path shows a login page. Due to misconfiguration, the default credentials admin:admin are accepted and the flag is displayed.

# http://<IP>/admin.php
# login: admin:admin
