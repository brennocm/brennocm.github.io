Dancing

HackTheBox, Very Easy

Dancing explores SMB (Server Message Block), a network file-sharing protocol on port 445. One of the shares allows passwordless access.

Reconnaissance

Nmap identifies port 445 open. The smbclient tool lists the available shares.

nmap -sS -sV <IP>
smbclient -L <IP>

The shares ADMIN$, C$, IPC$ and WorkShares are listed.

Exploitation

Only WorkShares is accessible without credentials, due to misconfiguration. Inside it, a user's directory holds the flag.

smbclient \\\\<IP>\\WorkShares
dir
cd James.P
get flag.txt
