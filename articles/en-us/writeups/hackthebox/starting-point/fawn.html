Fawn

HackTheBox, Very Easy

Fawn covers FTP (File Transfer Protocol), an unencrypted file-transfer protocol on port 21. The goal is to exploit a configuration that allows anonymous login.

Reconnaissance

After confirming the host with ping, Nmap identifies the FTP service on port 21.

ping -c4 <IP>
nmap -sV -sS <IP>

Exploitation

The server accepts the anonymous user, when misconfigured, anyone can log in anonymously. The flag is listed and downloaded.

ftp <IP>
# user: anonymous / pass: anonymous
dir
get flag.txt
