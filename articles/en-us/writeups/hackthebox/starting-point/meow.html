Meow

HackTheBox, Very Easy

Meow is the first lab of the Starting Point path and introduces the basics of reconnaissance and service enumeration. The focus is the Telnet protocol, an unencrypted remote-access service that, when misconfigured, allows login with default users.

Reconnaissance

Connectivity is validated with ping, followed by a service scan with Nmap. Only port 23 (Telnet) is open.

ping -c4 <IP>
nmap -sV -sS <IP>

Exploitation

With Telnet exposed, default users are tested. Logging in as root is accepted with no password, the result of a misconfigured service.

telnet <IP>
# login: root  (no password)
id
ls -la
cat flag.txt

Administrative access is obtained directly, and the flag is found in the user's directory.
